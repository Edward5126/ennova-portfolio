# E-nnova Portafolio Dual

Este repositorio contiene el código fuente del portafolio personal y profesional de Eduardo Chan. La arquitectura está diseñada en torno a un concepto de "Portafolio Dual", una Single Page Application (SPA) que permite al usuario alternar dinámicamente entre dos facetas profesionales sin recargar la página:

1.  **E-nnova Design:** Diseño UI/UX, Desarrollo Web Front-End e Identidad de Marca.
2.  **E-nnova Solutions:** Ingeniería Mecatrónica, Automatización Industrial (PLC/SCL) y Sistemas SCADA.
